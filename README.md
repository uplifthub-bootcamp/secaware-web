# secaware-web

The website for SecAware, a free platform for short cybersecurity-awareness courses. It has a learner area and an admin area, written in plain HTML, CSS and JavaScript with no framework or build step.

This repo is a training project. It has no features yet: it shows one placeholder page until the issues add them.

## Run it

Any static file server works. This one comes with PHP:

```sh
php -S 127.0.0.1:8080
```

Open <http://127.0.0.1:8080>. You should see the SecAware heading and "Coming soon".
